2.0.0, unreleased
    - Ctrl-Y copies a link to the highlighted note to the clipboard, for
      pasting into another note. The text is piped to the copy_command
      setting (e.g. pbcopy) if set, otherwise sent via OSC 52 to terminals
      that support it. yank_format picks wiki [[title]], markdown
      [title](path), title, or filename; yank_key changes the key
    - New optional dual-pane layout (layout = preview in ~/.tvrc or
      --layout preview): note list on the left, scrollable preview of the
      highlighted note on the right, stats bar at the bottom
    - Note: the abbreviated flag --l is now ambiguous (--layout vs
      --log-file); use --lo or --la
    - --version / -V prints the installed version
    - A config file given with -c must exist and be readable; a missing,
      unreadable, or directory path is now an error instead of silently
      falling back to the defaults
    - An extension with more than one dot (e.g. .page.md), a slash, or
      whitespace is now rejected; notes created with a multi-dot extension
      were never found by the scan. An empty extension is allowed;
      extensionless files that look binary (a NUL byte in the first 8 KB)
      are then skipped
    - The note list draws only the rows on screen, and each keystroke runs
      one search, so typing stays fast with tens of thousands of notes
    - Titles, contents, and queries are compared in Unicode NFC form, so
      accented names stored decomposed (common on macOS) are found
    - FIFOs and device files in the notes directory are skipped instead of
      hanging the scan
    - Control characters are stripped from pasted search text, and new
      note titles containing them are rejected
    - Ctrl-D no longer clears or quits; in the search box it deletes the
      character to the right. Use Esc or Ctrl-X
    - Removed -d/--debug, which logged nothing extra. The log file keeps
      warnings and errors and rolls over at 1 MB to ~/.tvlog.1
    - The exit status is nonzero when the app crashes
    - Fixed: a missing or misspelled editor froze the app
    - Hidden directories (.git, .trash, ...) are skipped when scanning, as
      hidden files already were
    - Fixed: new notes vanished from the list after editing when the
      configured extension was not in the extensions list
    - Fixed: titles that the scan would skip (hidden names, excluded
      directories) created an unreachable note; they are now rejected
    - Fixed: a failed note creation left behind the directories it made
    - Modernized to Python 3.11+ (dropped Python 2)
    - UI rewritten on Textual (urwid and chardet dependencies dropped)
    - Search is now in-memory with mtime-based cache invalidation: no disk
      reads while typing, fast startup and search with thousands of notes
    - Data safety: note files are never opened for writing; new notes are
      created atomically; browsing and searching never modify files
    - Runs on macOS and Linux
    - The notes directory is rescanned when the editor exits; Ctrl-R forces
      a full re-read (catches content changes that leave mtime and size
      intact)
    - The selected note stays selected after returning from the editor
    - Cache invalidation checks file size as well as mtime
    - Fixed: opening an existing note via Enter used a relative path
    - Fixed: opening an existing note failed on case-insensitive filesystems
    - Fixed: crash when notes_dir exists but is not a directory
    - Fixed: crash when launching the editor outside a real terminal
    - Fixed: crash on a malformed config file (now exits with a message)
    - Fixed: note titles can no longer escape the notes directory
    - Packaging: pyproject.toml and uv, a Makefile (dev, install, test, lint,
      fmt, package, publish, clean), console script entry points, a pytest
      test suite, and ruff
